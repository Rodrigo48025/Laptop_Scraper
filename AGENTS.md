# Project Instructions & Rules

- **No Emojis:** Do NOT use emojis anywhere in the user interface (no emoji icons in buttons, cards, badges, headings, notifications, or text). Always use clean Lucide SVG icons. Emojis look lazy and unprofessional.
- **Theme:** Default to a clean, crisp, premium White/Light theme with slate/neutral accents.
- **Utility:** Keep the UI decluttered, focused, and high-utility. Avoid vanity bloat.
- **Continuous Memory (GSD):** Always maintain and consult `.planning/STATE.md` at the project root for seamless continuity across model changes, restarts, and new sessions. Follow the Plan -> Execute -> Verify loop.

# UI Guidelines & Behavioral Rules

## 1. Strictly Prohibit Emojis in User Interfaces
- **NEVER** use emojis in the UI (buttons, headings, labels, badges, alert boxes, toasts, table columns, or empty states).
- Emojis look amateur, playful, and lazy.
- Always use vector icons (such as **Lucide React** icons) with appropriate size, stroke width, and color tokens.
- For status indicators, use clean geometric badges, colored indicator dots, or standard typographic chips.

## 2. Aesthetic & Color Theme
- The default UI theme must be **clean, modern white/light mode** (`bg-slate-50` canvas, `bg-white` cards and containers, subtle `border-slate-200` borders, crisp `text-slate-900` headings, and `text-slate-600` body text).
- Avoid dark mode unless explicitly asked.
- Avoid unnecessary clutter or vanity features. Maintain a clean, high-utility, professional interface.
